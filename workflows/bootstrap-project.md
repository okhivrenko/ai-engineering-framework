# Workflow: Bootstrap Project

Purpose: Prepare a repository so AI agents can operate with full project context.

Steps:
1. Add Project Context (name, goals, stack, constraints, main user journeys)
2. Add core rules and skills appropriate to the stack
3. Add CI validators for tests, accessibility, and security scans
4. Add minimal documentation (how to run, test, and deploy)
5. Add example issues or features to exercise the workflow

Verification:
- Project Context present and understandable
- CI validators run successfully on a sample PR
