# Workflow: Code Review

Purpose: Ensure proposed changes align with rules, tests, and architecture.

Steps:
1. Confirm PR links to acceptance criteria and decision records
2. Run CI and validators
3. Review tests and verify coverage for critical paths
4. Check for accessibility, security, and performance regressions
5. Provide focused feedback and request changes when necessary
6. Approve when requirements and rules are satisfied

Verification:
- No critical validator failures
- Reviewer confirms acceptance criteria satisfied
