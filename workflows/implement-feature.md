# Workflow: Implement Feature

Purpose: Standard steps an agent or developer follows to implement a feature from acceptance criteria to PR.

Steps:
1. Confirm acceptance criteria and update Project Context
2. Run quick architecture check (identify concerns and boundaries)
3. Propose minimal design and tests
4. Implement in small commits with tests
5. Run validators and local tests
6. Open PR with linked decision records and examples
7. Await review, address comments, merge after passing CI
8. Monitor post-deploy and update context if needed

Verification:
- PR includes tests and passes CI
- Decision record and context updated
