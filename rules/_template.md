# Rule Title

## Summary

Example: "Always provide explicit return types on public functions."

## Why

Example: "Explicit types prevent bugs, enable IDE support, and make code self-documenting."

State the rule clearly. Use imperative: "Always X", "Never Y", "Provide Z when..."
