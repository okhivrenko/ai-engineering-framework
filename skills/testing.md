# Skill: Testing

Purpose: Create and maintain automated tests that provide confidence in behavior.

Inputs:
- Acceptance criteria
- Code changes and design

Outputs:
- Unit, integration, and end-to-end tests
- Test strategy documented in PR

Steps:
1. Identify minimal unit tests needed for business logic
2. Add integration tests for critical interactions
3. Add E2E tests for major user flows
4. Ensure tests are deterministic and fast for CI

Verification:
- Test suite passes in CI
- Coverage targets met for critical modules
