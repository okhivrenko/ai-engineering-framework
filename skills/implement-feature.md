# Skill: Implement Feature

Purpose: Convert acceptance criteria into working, testable code and deliver a PR.

Inputs:
- Project Context
- Acceptance criteria
- Relevant rules and examples

Outputs:
- Implemented feature with tests
- Documentation and usage examples
- PR with linked decision records and context

Steps:
1. Confirm acceptance criteria and tests to satisfy them
2. Create a minimal design (components, APIs, data models)
3. Implement feature in small, testable commits
4. Run validators and tests locally
5. Open PR with description, tests, and documentation

Verification:
- All tests pass in CI
- Validators report no critical issues
- PR includes acceptance criteria and examples
