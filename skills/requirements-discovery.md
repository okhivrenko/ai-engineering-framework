# Skill: Requirements Discovery

Purpose: Elicit and structure requirements from stakeholders or existing artifacts.

Inputs:
- Project Context (if available)
- Stakeholder statements, issue descriptions, mockups

Outputs:
- Explicit acceptance criteria (Given/When/Then)
- Updated Project Context with clarified requirements
- Decision record for open trade-offs

Steps:
1. Summarize the stated request in one sentence
2. Ask 3 clarifying questions targeting edge cases
3. Propose minimal acceptance criteria and example scenarios
4. Confirm with stakeholder or create a lightweight spike
5. Update Project Context and decision record

Verification:
- Acceptance criteria are present in Project Context
- At least one example scenario with expected outcome
- Stakeholder confirmation recorded (or documented rationale)
