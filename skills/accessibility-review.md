# Skill: Accessibility Review

Purpose: Validate UI and user-facing changes for accessibility compliance.

Inputs:
- PR with UI changes, examples, and accessibility tests
- Project accessibility goals and standards

Outputs:
- Accessibility review comments or approval
- Required remediation steps and tests

Steps:
1. Run automated accessibility checks (a11y linters)
2. Inspect keyboard navigation and focus management manually
3. Verify color contrast and readable typography
4. Confirm alt text and media captions
5. Record results and required changes in PR

Verification:
- Automated checks pass or have documented acceptable exceptions
- Manual verification of critical interactions completed
